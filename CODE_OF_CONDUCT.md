# Code of Conduct

Be kind, be precise, assume good faith — in this order.

- We are here to build a tool people trust with their terminals and their keys.
- Critique the code, never the person.
- No harassment, discrimination, doxxing, or pressure to share credentials.
- If you see a violation, report it privately via a GitHub Security Advisory
  (the Security tab) with the word "conduct" in the title.

Violations: a warning, then a temporary or permanent ban from the project.
Maintainers' decisions are final; if disagreement persists, take it to the
advisory draft and argue your case — do not escalate publicly.
